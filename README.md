A word we need, coined for the make.fun bounty "Invent a Word We
Need": **hallucitation** — a confident citation of a document that
does not exist, delivered with a page number. Until now the phenomenon
had no name, which is how it kept getting into reports, briefs and
bibliographies unchallenged.

## Running it

`node main.ts` clears the output directory's contents and writes the
coinage to `/output/entry.txt` as plain UTF-8 text.
